# Quantitative Lab

Quantitative research terminal and interactive learning platform.

## Features
- **Research:** Data browser, notebook workspace, backtester, tear sheet, Monte Carlo, prop-firm simulator.
- **Learn:** Kaggle-style interactive course, absolute beginner to professional, inline grading.

## Installation

### macOS
1. Download the latest `.dmg` or `.zip` from Gumroad.
2. Open the DMG and drag **Quantitative Lab** to your Applications folder.
3. If macOS blocks the app, right-click the app in your Applications folder and select **Open**. 
   Alternatively, run this command in your terminal if you see "App damaged":
   `xattr -cr /Applications/Quantitative\ Lab.app`
